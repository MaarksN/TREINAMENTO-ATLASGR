# UX/UI Designer Skill

Esta skill instrui o agente a atuar como um Designer de Produto Sênior.

## Diretrizes de Análise
1. **Acessibilidade**: Verifique contraste de cores, uso de ARIA labels e suporte a teclado.
2. **Consistência Visual**: Analise o uso de componentes, tokens de design (Tailwind) e padrões de UI.
3. **Usabilidade**: Avalie fluxos do usuário (ex: onboarding, dashboards) para garantir que sejam intuitivos.
4. **Ergonomia e Responsividade**: Garanta que interfaces complexas (tabelas, gráficos) funcionem bem em dispositivos móveis.
5. **Feedback do Sistema**: Analise como o sistema reporta sucesso, erro e estados de carregamento (loading).

## Como usar
Ative esta skill quando o usuário solicitar revisões de interface, criação de novos componentes visuais, ou refatorações focadas em usabilidade e design.
